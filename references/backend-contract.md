# 后端能力映射

以下是能力约定，不代表这些工具已经安装，也不是必须照搬的固定 API。读取目标环境实际提供的工具定义或 CLI 帮助后再调用。不要猜测参数、URL 或本地安装路径。

| 能力 | 常见 MCP 名称 | 必须核对的内容 |
|---|---|---|
| 状态 | `wechat_status` | 账号、最后检查时间、最新消息时间、缺失分片、错误和时区 |
| 联系人 | `wechat_contacts` | 显示名、备注、账号标识、重名和群聊歧义 |
| 搜索 | `wechat_search` | 搜索语义、聊天/发送者/日期筛选、分页上限 |
| 上下文 | `wechat_context` | 使用搜索返回的消息 ID，读取同一聊天相邻消息 |
| 媒体证据 | `wechat_media` 或同等能力 | 缓存状态、缩略图标记、OCR/转写来源和可信程度 |
| 笔记正文 | 可选的提取工具或 CLI | 从同一账号的工作副本读取，并过滤 XML 中的密钥和私有下载地址 |

## 接入参数

每个账号单独配置这些字段或对应能力：

- `account_label`：用户自定的本地账号标签。
- `source_dir`：用户自己的微信数据库来源目录，只供已有同步后端使用。
- `state_dir`：与来源隔离的私有工作副本和索引目录。
- `self_id`：用户自己的账号标识，用于正确显示“我”。
- `existing_key_files`：已有密钥文件的位置，只供后端内部读取，不返回内容。
- `timezone`：数据的时间解释方式和输出时区。

不要复用其他账号的索引、消息 ID 或密钥配置。配置模板中的字段名称需要适配实际后端；本分享包没有读取这些字段的运行程序。

## 刷新和资源

查询与刷新分开。优先复用已有刷新进程及互斥锁；每个账号最多一个刷新任务，默认串行。启动刷新前检查 CPU、可用内存、交换空间、进程数、磁盘空间和 I/O。给任务设置有限超时和重试次数。结束后回收本任务新增进程；不能按名称批量结束其他进程，也不重启机器。

刷新失败时保留原因与覆盖缺口。状态中“检查完成”“最新消息时间”和“数据完整性”不能互相替代。
